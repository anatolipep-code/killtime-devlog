# KILLTIME devlog

Public media and notes for the KILLTIME devlog (X / Instagram).
KILLTIME is a PC first-person extraction shooter built by Claude and one human developer.

Each entry lives in `entries/YYYY-MM-DD_slug/`: a `note.md` with what was done and by whom, plus images.
Renders are labelled as renders. Nothing here is presented as gameplay unless it is gameplay.
